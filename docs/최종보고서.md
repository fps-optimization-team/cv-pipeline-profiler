# 📊 [최종 보고서] 비전 파이프라인 성능 최적화 및 벤치마크 결과

## 1. 프로젝트 요약
본 프로젝트는 초록색 객체(공)를 검출하는 비전 파이프라인의 프레임 처리 속도(FPS)를 향상시키기 위해 수행되었습니다. 단일 스레드 기반 Baseline(V1)부터 I/O 멀티스레딩(V2), 그리고 알고리즘/연산 최적화(V3)를 단계별로 적용하며 실측 벤치마크를 수행했습니다.

---

## 2. 주요 구현 및 최적화 성과

### ① I/O 병목 제거 (V2 - Multi-threaded Queue)
* VideoCapture I/O와 Main Processing 루프를 독립 스레드로 분리하여 Frame Drop 및 입력 병목을 방지했습니다.
* 스레드 간 `queue.Queue(maxsize=5)`를 활용한 안전한 프레임 전달 및 동기화를 구현했습니다.

### ② 연산 및 알고리즘 최적화 (V3 - Algorithm Optimization)
* **Downsampling & Upscaling:** 연산 영역 해상도를 0.5배 축소 후 결과를 원본 좌표로 역복원하여 연산량을 대폭 감소시켰습니다.
* **관심 영역(ROI) 추적:** 이전 프레임의 검출 위치 주변으로 연산 범위를 국한하여 불필요한 전체 이미지 탐색을 방지했습니다.
* **N-Frame Skip & Fast Interpolation:** 2프레임 간격 추적 재사용 및 `INTER_NEAREST` 빠른 보간법을 적용했습니다.
* **OpenCV Thread Control:** `cv2.setNumThreads(1)`을 통해 CPU 멀티스레드 오버헤드를 제어했습니다.

---

## 3. 성능 측정 및 결과 분석

### 3.1 벤치마크 실측 데이터 (Summary)

* **1920x1080 (FHD):**
  * V1: 58.14 FPS → V2: 78.46 FPS (**+34.93%**) → V3: 105.29 FPS (**+81.09%**)
* **1280x720 (HD):**
  * V1: 144.96 FPS → V2: 197.50 FPS (**+36.24%**) → V3: 288.61 FPS (**+99.09%**)
* **640x480 (VGA):**
  * V1: 652.71 FPS → V2: 830.14 FPS (**+27.18%**) → V3: 1329.22 FPS (**+103.65%**)

### 3.2 핵심 인사이트
1. **계단식 성능 향상 검증:** 모든 해상도 조건에서 $V1 < V2 < V3$ 순으로 FPS가 크게 증가함을 검증했습니다.
2. **연산 효율의 극대화:** V3 적용 시 high-resolution(1080p) 환경에서도 실시간 처리 한계(60 FPS)를 크게 상회하는 105 FPS 이상을 달성했습니다.
3. **I/O 및 알고리즘 분리 효과:** V2를 통해 I/O 대기시간을 약 30% 개선하였으며, V3를 통해 알고리즘 연산 시간을 추가로 약 50% 이상 단축시켰습니다.

---

## 4. 결론 및 향후 과제
* **결론:** I/O 스레딩 분리 및 Downsampling/ROI 연산 최적화를 통합 적용함으로써, 원본 화질의 검출 성능을 유지하면서 처리 속도를 **최대 2배(103.65% 상승)** 이상 향상시키는 데 성공했습니다.
* **향후 과제:** OpenCL 가속 기반의 `cv2.UMat` 파이프라인 활성화(`use_umat=True`) 및 GPU 하드웨어 가속 환경에서의 추가 벤치마크 수행.
