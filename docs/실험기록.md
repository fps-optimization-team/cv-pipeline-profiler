# 🧪 비전 파이프라인 성능 최적화 및 벤치마크 실험 기록

## 1. 개요 및 목적
* **목적:** 초록색 객체(공) 검출 파이프라인의 단계별 최적화(I/O 스레딩, 알고리즘 개선)를 적용하고, 해상도별 성능(FPS)을 정량적으로 측정 및 비교 분석
* **테스트 영상:** 70초 분량 샘플 영상 3종 (`640x480`, `1280x720`, `1920x1080`)
* **설정 일원화:** `config.json`을 통해 파라미터(커널 크기, Threshold 등)를 일원화 관리

---

## 2. 파이프라인 버전별 주요 특징 및 최적화 기법

### 2.1 공통 영상 처리 파이프라인
* **전처리 (Pre-processing):** `cv2.GaussianBlur` 노이즈 제거 및 BGR → HSV 색상 공간 변환
* **검출 (Detection):** 설정된 HSV 범위 (`lower_green`, `upper_green`) 기반 마스킹 (`cv2.inRange`)
* **후처리 (Post-processing):** 잡영 제거 및 구멍 채우기를 위한 모폴로지 연산(Opening/Closing) 및 외곽선 추출 (`cv2.findContours`)
* **결과 표시 (Rendering):** 검출 객체 최소 외접원, Bounding Box 및 식별 라벨("Green Circle") 렌더링

### 2.2 버전별 구현 요약
* **V1 (단일 스레드 - Baseline):**
  * Frame Read, Processing, Rendering, Display가 단일 메인 스레드 루프에서 순차 실행되는 기준 파이프라인
* **V2 (멀티스레드 - Producer-Consumer):**
  * `threading.Thread` 기반 Frame Producer(영상 읽기) 스레드 분리로 I/O 병목 제거
  * `queue.Queue(maxsize=5)`를 이용한 스레드 간 데이터 전달 및 `queue.Full` 발생 시 대기/재시도 동기화 메커니즘 적용
  * `threading.Event`를 통한 데드락 방지 및 안전한 스레드 종료 처리
* **V3 (알고리즘 및 연산 최적화):**
  * Processing 해상도 Downsampling (`scale_factor=0.5`) 후 원본 좌표 역복원
  * 이전 검출 영역 기반 동적 관심 영역(ROI) 국한 연산 (`use_roi=True`)
  * 빠른 보간법 (`cv2.INTER_NEAREST`) 및 N-Frame Skip (`skip_interval=2`) 적용
  * 불필요한 스레드 오버헤드 방지를 위한 OpenCV 내부 스레드 제어 (`cv2.setNumThreads(1)`)
  * (`cv2.UMat` 기반 OpenCL 가속 옵션 보유, 기본 실행 시 `use_umat=False` 설정)

## 3. 측정 및 벤치마크 환경 (Measurement & Benchmarking)

* **이동평균 FPS:** 최근 30프레임 간의 연산 시차를 기반으로 한 이동평균 FPS 계산
* **단계별 소요 시간(ms):** `StepTimer`를 활용해 `전처리`, `검출`, `후처리`, `그리기` 각 단계 소요 시간을 `time.perf_counter()` 기반 측정
* **벤치마크 자동화 (`benchmark.py`):**
  * 해상도 3종 × 버전 3종 (총 9가지 조건) 조건별 3회 반복 실행
  * 조건별 평균 FPS, 표준편차, V1 대비 성능 향상률(%) 산출
  * `fps_comparison_table.csv` 및 `fps_benchmark_summary.csv` 결과 누적 저장
  * 직전 vs 현재 측정 결과를 직관적으로 비교하는 Matplotlib 막대그래프 (`fps_benchmark_graph.png`) 자동 생성
